**Punto clave:** ningún dataset actual tiene hologramas/fase de eritrocitos *infectados*. El dataset QPI es de donantes sanos; el de malaria no es holográfico. Las 3 opciones de abajo dependen de cómo se resuelva ese vacío.

## 3 opciones de problema

1. **Reconstruir fase (holograma→fase) con el dataset de eritrocitos sanos.** Tarea de reconstrucción QPI pura vía deep learning, usando los pares reales disponibles. No toca malaria directamente — sería la base técnica, con la infección como motivación/contexto en la introducción.
2. **Detectar malaria desde QPI.** Requeriría mapas de fase de eritrocitos *infectados* etiquetados, que no existen en ninguno de los dos datasets. Bloqueada hasta no resolver el vacío de datos.
3. **Expandir el dataset.** Usar el pipeline de reconstrucción de fase (validado en eritrocitos sanos) como base para curar/generar un dataset de hologramas + fase de eritrocitos infectados con malaria, habilitando más adelante las opciones 1/2. Requiere acceso a muestras DHM de malaria (no confirmado) o algún método de aproximación (simulación, generación).
